视频进度条工具 —— 使用说明
========================================

一、怎么打开
  解压后，双击文件夹里的「启动进度条工具.cmd」。
  会弹出一个独立窗口（只有工具的界面，没有地址栏）。
  同时会有一个最小化的黑窗口，那是后台进程，可以不管它。

  如果双击后没反应，改双击「调试启动.cmd」，它会保留窗口显示详细信息。

二、怎么用（4 步）
  1. 选素材：点「选择视频」，也可以把视频文件直接拖进窗口。
  2. 切段落：填段数点「平均分成 N 段」，或手动添加。
  3. 调样式：右边改什么，左边预览立刻跟着变。
  4. 导  出：底下选格式和保存位置，点「开始导出」。

三、导出的文件在哪
  默认存在原视频所在的文件夹，文件名是「原文件名_进度条」。

  ⚠ 重要：双击导出的 .mov 打不开、甚至提示「文件已损坏」是正常的！
     带透明通道的 .mov 就是不能在 Windows 自带播放器里播，它是给剪辑软件用的。
     想确认效果：导出完成后点「生成可直接播放的预览版」，会得到一个深色底的 MP4，
     那个可以双击直接看。真正要用的时候，把 .mov 拖进剪映 / Pr / 达芬奇即可。

四、常见问题
  Q：需要先装什么环境吗？
  A：不需要。Node.js 和 ffmpeg 都已经打包在本文件夹的 bin 目录里，解压即用。
     如果你电脑上装了剪映、Pr 等剪辑软件，工具也会自动去找它们自带的 ffmpeg。

  Q：会联网吗？会改我的原视频吗？
  A：都不会。所有处理都在你自己电脑上完成，只读取视频信息，不动原文件。

  Q：导出要多久？
  A：1080p、30 帧、1 分钟的视频大约 15~20 秒。导出过程中会显示进度和预计剩余时间。

  Q：导出的 .mov 导不进剪辑软件怎么办？
  A：在「导出格式」里换成「ProRes 4444」再导一次，那个兼容性最保险。

  Q：双击时 Windows 弹出安全提示？
  A：这是 Windows 对「从网上下载的脚本文件」的常规提示，并不是报毒。
     点「更多信息」→「仍要运行」即可。
